# 中文式日语对照

中文母语者写日语简历和专业文书时，容易把中文的搭配、缩写和语气直接搬到日语里。下面按类别列出常见模式、错误的直译和自然的写法。每一条都要结合上下文判断，不要机械替换。

## 格式

```
### 类别
- 中文：<中文说法>
- 错误：<不自然的日语>
- 自然：<自然的日语>
- 说明：<为什么错、什么时候用>
```

## 技术术语

### 运行基础 / 运行时
- 中文：运行基础、运行时基础、运行基座
- 错误：実行基盤
- 自然：実行環境 / ランタイム基盤 / 実行インフラ
- 说明：実行基盤 不是标准日语词。日语把「运行环境」和「基础设施」分开说。

### 音视频
- 中文：音视频
- 错误：音動画
- 自然：音声・動画 / オーディオ・ビデオ
- 说明：音動画 不是日语词。中文可以自由缩略「音频＋视频」，日语要用完整说法或外来语。

### 大 DAU 产品
- 中文：大 DAU 产品、大规模 DAU 产品
- 错误：大規模DAU製品
- 自然：DAU数千万規模のアプリ / 大規模ユーザー向け製品
- 说明：DAU 是指标，不是产品类别。日语只能说「有 X 万 DAU 的产品」，不能说「DAU 产品」。

### 编译时转换
- 中文：编译时转换、编译时方案
- 错误：コンパイル時変換
- 自然：コンパイル時コード変換 / ビルド時トランスパイル / コンパイル時最適化
- 说明：单独一个「変換」太含糊。日语技术写作会说明转换的对象（代码、AST），或直接用精确的英文词。

### 播放性能
- 中文：播放性能
- 错误：再生性能
- 自然：再生パフォーマンス / 再生品質
- 说明：性能 能听懂，但软件性能指标在日语技术写作里通常用 パフォーマンス；指流畅度、画质时用 品質。

### 优化方向
- 中文：优化方向、改善方向性
- 错误：方向性を改善する
- 自然：方向性を見直す / 方向性を最適化する / 方向性を定める
- 说明：改善する 搭配有明确好坏状态的对象（品質、効率、プロセス）。方向性 搭配 見直す、定める、最適化する。

## 公司、产品与团队名

### 展销
- 中文：展销
- 错误：展销（原样保留）
- 自然：販促・展示 / 販売促進
- 说明：展销 是国内互联网团队的命名习惯（展示＋销售），日语没有这个缩略，按职能翻译。

### B 端
- 中文：B 端
- 错误：B端（原样保留）
- 自然：B向け / 法人向け / 店舗・倉庫向け（按语境）
- 说明：端 是中文技术口语里的「一端」，日语用 向け。语境清楚时可以写「B端（店舗・倉庫向け）」。

### 智能设备（仓库场景）
- 中文：智能设备
- 错误：スマートデバイス（太笼统）
- 自然：業務用ハンディターミナル / 業務用タブレット
- 说明：スマートデバイス 在日语里指任何智能设备。仓库场景要写具体设备类型。

### Android Launcher
- 中文：Android Launcher、桌面启动器
- 错误：Android Launcher（留英文）
- 自然：Androidランチャー / Android ランチャー
- 说明：日语技术写作会把这类词片假名化。

### 广告中介 SDK
- 中文：广告中介 SDK、Mediation SDK
- 错误：広告Mediation SDK
- 自然：広告メディエーションSDK
- 说明：Mediation 要片假名化。汉字和英文混在一起的复合名词看起来不专业。

## 语气与写法

### 自我贬低式开场
- 中文：不是商业级成果，只是……
- 错误：商用規模の実績としてではなく、自主的な学習……
- 自然：削掉，或正面重写：個人プロジェクトとして〜を運用し、〜に取り組んでいる
- 说明：不要主动声明某件事「不厉害」。日语简历不用这种防御性语气；值得写就正面写。

### 「体现了……态度」
- 中文：体现了……的态度、展示了……的姿态
- 错误：〜する姿勢を示す活動です
- 自然：削掉框架，直接写事实：〜に取り組んでいる / 〜を継続している
- 说明：姿勢を示す 像学生交自我反思，职业简历不这么写。

### 「任期内未出事故」当成成果
- 中文：任期内未出现线上事故
- 错误：重大な本番障害を起こすことなく
- 自然：削掉（这不算成果），或改写成：安定的に運用を継続し、〜件のリリースを成功させた
- 说明：不出事故是基本要求。把它写成成绩会显得标准很低。确实要讲稳定性，就配一个正面数字（发布次数、可用率）。

### 「尝试使用」
- 中文：尝试使用、试用
- 错误：〜を試しています
- 自然：〜を実践的に活用している / 〜に取り組んでいる
- 说明：試しています 听起来还在试验阶段、没做出东西。用表示持续、产出的说法。

### 「如果公司需要，也可以……」
- 中文：如果公司需要，也可以……
- 错误：会社や事業上の必要があれば、〜も活かせます
- 自然：从希望職種里删掉，留到面谈时说
- 说明：这句话听起来像「我不想做，但被要求就做」。希望職種 里只写正面能提供的东西，灵活性留到对话里处理。

## 姓名与格式

### 姓名读音的分隔
- 中文：姓 名（如「王小明」）
- 错误：オウ　ショウメイ（姓和名之间用全角空格）
- 自然：オウ・ショウメイ（中黑点 U+30FB）
- 说明：日语行文里姓和名的读音用 ・ 分隔。全角空格看起来像排版错误。读音本身按本人确认的写法，不要凭汉字猜。
